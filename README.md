# 🌍 Air Quality Analysis

## 📌 Project Overview

**Air Quality Analysis** is a simple data analysis and visualization project that compares air quality levels across different cities.

The project focuses on three important air-quality measurements:

- 📊 **AQI (Air Quality Index)**
- 🌫️ **PM2.5**
- 💨 **PM10**

The analysis presents the data in an easy-to-understand format using visualizations, making it easier to compare pollution levels between cities.

---

## 🎯 Project Objectives

The main objectives of this project are:

- 🌆 Compare air quality across different cities.
- 📈 Analyze AQI levels for each city.
- 🌫️ Understand PM2.5 concentration levels.
- 💨 Compare PM10 concentration levels.
- 📊 Represent air-quality data using clear visualizations.
- 🔎 Identify cities with comparatively higher and lower pollution levels.

---

## 🗂️ Project File

**Air_Quality_Analysis.ipynb**

This Jupyter Notebook contains the complete analysis, dataset, and visualizations for the project.

---

## 📋 Dataset

The project uses air-quality data for the following cities:

- Mumbai
- Delhi
- Ahmedabad
- Bangalore
- Kolkata
- Chennai

The dataset contains:

| Column | Description |
|---|---|
| 🏙️ City | Name of the city |
| 📊 AQI | Air Quality Index value |
| 🌫️ PM2.5 | Fine particulate matter concentration |
| 💨 PM10 | Particulate matter concentration |

---

## 📊 Analysis & Visualizations

The notebook includes visual analysis of:

### 1. 🌆 City-wise AQI Levels

A visualization is used to compare the AQI values of different cities.

It also highlights the **100 AQI reference level** to make the comparison easier.

### 2. 🌫️ PM2.5 vs PM10 Comparison

A second visualization compares PM2.5 and PM10 levels across all the cities.

This helps in understanding how particulate pollution differs from one city to another.

---

## 🔍 Key Observations

Based on the dataset used in the notebook:

- 🟥 **Delhi** has the highest AQI among the listed cities.
- 🟠 **Kolkata** and **Ahmedabad** also show relatively high AQI values.
- 🟢 **Bangalore** has the lowest AQI in the given dataset.
- 🌫️ Delhi also has the highest PM2.5 and PM10 values.
- 📉 Bangalore and Chennai show comparatively lower particulate matter levels.
